# ADR 0077: компактный просмотр материалов и импорт эталонных черновиков

## Статус

Согласовано владельцем 2026-10-08: убрать счётчики и загрузить предоставленные
67 эталонных кейсов компактно, без автоматического утверждения ответов.

## Решение

- В группах проверки показывать текстовый статус, без счётчиков материалов и
  отношений 0/0, 7/7. Сами численные поля API и проверки комплектности сохраняются.
- Проверенные клинические справочники не становятся нормативными актами. Из
  нормативной библиотеки владелец/юрист с существующим доступом LEGAL_EDITOR
  может перейти к ним отдельной кнопкой. Не расширять доступ других пользователей.
- Импортировать строки XLSX в существующее tenant-scoped рабочее место эталонов
  через API создания и загрузки файла, только как DRAFT, от владельца-contributor.
- Краткая карточка содержит заголовок, исходный код, фабулу, вопрос, кандидат
  короткого ответа и явное предупреждение. Все значения каждой исходной строки,
  включая полный ответ, даты и пометки ассистента, сохраняются в приватном TXT.
- Заголовок карточки `Название: ...` может быть отображён как компактный displayName
  только внутри уже защищённого рабочего места; свободная фабула и удалённое
  содержимое по-прежнему получают общий номер. API shape не изменяется.
- Дата оценки импорта задаётся оператором явно и не считается датой события
  или редакции документа. ABSTAIN — явно обозначенный стартовый параметр черновика,
  поскольку ожидаемые маршруты не заданы в исходнике. Он не утверждается импортом.
- Полная предварительная валидация пакета: bounded schema, группы из таблицы,
  уникальные исходные коды, отсутствие обнаруженных прямых идентификаторов.
  При ошибке остановиться до начала записи. Исходные XLSX и тексты не входят в git,
  fixtures, логи, нормативный retrieval, обучающий набор или запросы моделей.
- Ключи повторной загрузки привязаны к SHA исходника и коду строки; payload checks
  существующего API запрещают тихую замену содержимого. Повторная загрузка не
  создаёт дубли; при частичной ошибке продолжается с теми же ключами.

## Границы и проверка

Существующие clinic_id, grants, RLS, аудит, приватное хранилище и срок хранения
черновиков 30 дней действуют без изменений. Новых таблиц/миграций, ролей, источников
права и risk policy нет. Проверенные справочники, утверждённые нормы и проверенные
ответы эталонов остаются тремя разными состояниями.

Unit/PG проверки: отсутствие счётчиков, ограниченные названия, полный исходник,
privacy отказ, duplicate/retry, авторизация, доступ юриста к файлу и невозможность
утвердить DRAFT. После выпуска — 67 карточек и файлов, совпадение хешей содержимого,
доступ владельца/юриста, актуальный v4 и отсутствие нормативных approval событий
от импорта. Нельзя считать юридическое качество 67 ответов подтверждённым.
