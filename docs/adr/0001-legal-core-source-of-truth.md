# ADR-0001: Legal Core — источник юридической истины

- Статус: принято ТЗ v0.1
- Дата: 2026-08-22

## Контекст

Система использует LLM-оркестрацию, но юридические нормы меняются во времени, требуют проверяемых источников и не могут безопасно извлекаться из памяти модели.

## Решение

Hermes Agent используется только как оркестратор. Нормативные документы, их неизменяемые версии, effective dates, lifecycle, approved index и evidence metadata принадлежат отдельному Legal Core.

Каждый значимый legal claim обязан ссылаться на retrieved fragment. Отсутствие или конфликт evidence приводит к uncertainty/эскалации, а не к восстановлению нормы из памяти модели. Production retrieval видит только `APPROVED` версии. Новая редакция не перезаписывает историческую.

## Последствия

- Agent runtime и LLM provider можно заменить без миграции нормативного корпуса.
- Ingestion/update pipeline остаётся детерминированным до этапа анализа.
- Потребуются version resolver, regression gate и ручное утверждение спорных обновлений.
- Ответы воспроизводимы по legal snapshot, model/policy versions и fragment IDs.
