# Команда клиники

Раздел доступен только владельцу соответствующей клиники в личном чате с ботом.
Он показывает активных сотрудников по Telegram ID и роли: владелец,
администратор или юрист. В сообщении отображаются первые 50 сотрудников;
если список длиннее, это явно указано.

Для добавления выберите «Добавить юриста» или «Добавить администратора» и
отправьте Telegram ID одним положительным числом. После успешного добавления
список обновляется из Legal Core. Кнопка главного меню отменяет ввод.

Юрист работает с эскалациями HIGH/CRITICAL. Добавление в команду не назначает
роль LEGAL_EDITOR, не даёт права утверждать нормативную базу и не открывает
данные других клиник. Проверки владельца, клиники и разрешённых ролей выполняет
существующий API `/v1/clinic/members`; его контракт и права не изменены.
